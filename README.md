# Gerador de QR Code

Gerador de QR Codes personalizados a partir de textos ou URLs, desenvolvido com HTML, CSS e JavaScript puros.

## Funcionalidades

* Geração de QR Code a partir de qualquer texto ou link
* Escolha de tamanho (200 a 1000 px) e nível de correção de erro
* Cores personalizadas para o código e o fundo
* Download em PNG ou SVG (vetorial, ideal para impressão)
* Layout responsivo com suporte a tema escuro automático

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Digite o texto ou URL no campo **Conteúdo**.
3. Ajuste as opções, se quiser, e clique em **Gerar QR Code** (ou pressione Enter).
4. Baixe o resultado em PNG ou SVG.

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* [API goQR.me](https://goqr.me/api/) para geração das imagens
